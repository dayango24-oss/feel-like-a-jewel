# Feel Like A Jewel — GitHub Pages Website

A responsive, static FLJ website built around the black / rose-gold / white visual identity in the supplied brand artwork.

## Publish with GitHub Pages

1. Create a new GitHub repository, for example `feel-like-a-jewel`.
2. Upload `index.html`, `styles.css`, `script.js`, and `FLJ-Thank-You.png`.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. GitHub will provide your public website address.

## Customize first

- Replace the three sample product cards with your real products.
- Replace `YOUR_EMAIL@example.com` in `index.html`.
- Add your social-media links.
- Add your shipping, refund, privacy and terms pages.
- If you sell regulated/health-related products, review all product claims and compliance requirements before publishing.
